What is HTML ?


HTML stands for HyperText Markup Language.

HTML is the standard markup language used to create and structure web pages.
HTML tells the browser what content should appear on a webpage, such as:

বাংলা:
HTML-এর পূর্ণরূপ HyperText Markup Language।
HTML ব্যবহার করে আমরা একটি ওয়েবপেজের কাঠামো (Structure) তৈরি করি।
যেমন একটি ওয়েবসাইটে থাকে:

  • Heading
  • Paragraph
  • Image
  • Link
  • Button
  • Table
