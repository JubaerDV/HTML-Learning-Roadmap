📚 HTML Beginner Course

🌐 What is HTML?

HTML = HyperText Markup Language

HTML is used to create the structure of a web page.

Think of a website like a house:

🧱 HTML → Structure of the house

🎨 CSS → Colors, design, layout

⚙️ JavaScript → Behavior and interaction

For Example:

WEBSITE

HTML → CSS → JavaScript

Structure = HTML
Design = CSS
Behavior = JavaScript

HTML tells the browser things like:

  • "This is a heading."
  • "This is a paragraph."
  • "This is an image."
  • "This is a button."
  • "This is a link."

🧠 First thing you should understand: HTML uses tags

HTML is built using tags.

For example:

Hello World

Here:

<h1> = Opening tag

</h1> = Closing tag

Together:

<h1>Hello World</h1>

This creates a heading.

The browser displays:

Hello World

Another example:

<p>I am learning HTML.</p>

<p> means paragraph.

🔍 Now understand what you wrote

Don't try to memorize everything yet.
Let's break it down.

<!DOCTYPE html>

<!DOCTYPE html>

This tells the browser:

"This document is HTML5."

You'll normally put it at the very beginning of an HTML page.

<html>

<html>

This represents the beginning of the HTML document.

The whole page goes inside it.

<head>

<head>

The <head> contains information about the webpage.

For example:

<head>
    <title>My First Website</title>
</head>

The title appears in the browser tab.

<title>

<title>My First Website</title>

This controls the browser tab title.

<body>

This is extremely important.

The <body> contains the content that users see on the webpage.

For example:

<body>

    <h1>Hello World!</h1>

    <p>I am learning HTML.</p>

</body>

🏷️ Your first important HTML tags

You don't need hundreds of tags.
Start with these.

  • <h1> → Main heading
  • <h2> → Second-level heading
  • <h3> → Third-level heading
  • <p> → Paragraph
  • <a> → Link
  • <img> → Image
  • <ul> → Unordered list
  • <ol> → Ordered list
  • <li> → List item
  • <button> → Button
  • <br> → Line break
  • <hr> → Horizontal line
  • <div> → General container
  • <span> → Inline container

Don't try to memorize this table.
You'll learn these naturally by using them.

🧩 Very important concept: Nesting

You'll see HTML like this:

<html>
    <head>
        <title>My Website</title>
    </head>

    <body>
        <h1>Hello</h1>
        <p>Welcome to my website.</p>
    </body>
</html>

Notice how the tags are inside other tags.

This is called nesting.

Think of boxes:

<html>
├── <head>
│    └── <title>
│
└── <body>
      ├── <h1>
      └── <p>

Understanding nesting is one of the most important things for a beginner.

🧱 HTML Elements

You will often hear the word element.

For example:

<h1>Hello</h1>

The entire thing is an HTML element.

Another example:

<p>Hello, I am learning HTML.</p>

Generally:

Opening Tag
↓
<p>
↓
Content
↓
Hello World
↓
Closing Tag
↓
</p>

Together:

<p>Hello World</p>

🏷️ Attributes

After you understand basic tags, you'll learn attributes.

For example:

<a href="https://www.google.com">Google</a>

Here:

href="https://www.google.com"

is an attribute.

It gives additional information to the <a> element.

Another example:

<img src="photo.jpg" alt="My photo">

Here:

src="photo.jpg"

and

alt="My photo"

are attributes.
